# Implantação

O contexto da plataforma registra Apache/Gunicorn e uso anterior de Docker/WSL2. Conferir a configuração atual na VM antes de importar arquivos de implantação.

Documentar proxy, entrypoint da fábrica Flask, variáveis necessárias sem valores secretos, conexão PostgreSQL e procedimento de migração. Não foram gerados Dockerfile, compose ou configuração Apache sem essa conferência.
