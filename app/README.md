# Aplicação web

Destino inicial da aplicação Flask existente na VM. Preservar `create_app()`, blueprints e convenções `routes.py`/`service.py` ao importar.

As pastas dashboard, portal_treinamento, templates e static refletem os módulos e recursos mencionados no contexto. Conferir os caminhos reais antes de mover arquivos; módulos adicionais devem manter seus nomes existentes.

Não foram criados arquivos Python vazios nem uma segunda implementação. Dependências, entrypoint e comandos de execução serão documentados após conferência da aplicação real.
